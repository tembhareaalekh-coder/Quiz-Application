🎯 Quiz Application

A modern and responsive online quiz application built to provide an interactive way to test knowledge through multiple-choice questions.

🚀 Live Demo

"Try the Quiz Application" (https://quiz-application--aalekhtembhare.replit.app/)

✨ Features

- 📚 Multiple quiz categories
  - Programming
  - Computer Fundamentals
  - General Knowledge
- 🎯 Multiple difficulty levels
- 🔀 Randomized questions
- ⏱️ 30-second timer for each question
- 📊 Question progress indicator
- 🧮 Automatic score calculation
- ✅ Correct and incorrect answer tracking
- 📝 Quiz result summary
- 🔍 Answer review
- 🏆 High score tracking
- 🔄 Restart quiz functionality
- 📱 Mobile-friendly responsive design

🛠️ Tech Stack

- TypeScript — Application logic and functionality
- HTML — Structure of the application
- CSS — Styling and responsive design

🎮 How It Works

1. Select a quiz category.
2. Choose a difficulty level.
3. Start the quiz.
4. Answer the questions before the timer runs out.
5. View your score and performance.
6. Review your answers and try again.

💡 Project Purpose

This project was developed as a practical web development project to demonstrate interactive user interfaces, quiz logic, state management, timer functionality, and responsive web design.

⚙️ Run Locally

Clone the repository and install the required dependencies:

git clone <YOUR-GITHUB-REPOSITORY-URL>
cd Quiz-Application
npm install
npm run dev

Then open the local development URL shown in the terminal.
