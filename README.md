# Quiz Application

A modern and responsive online quiz application designed to test knowledge through interactive multiple-choice quizzes.

## Features
## Live Demo

🚀 [Try the Quiz Application](https://quiz-application--aalekhtembhare.replit.app/)

- Multiple quiz categories
- Programming, Computer Fundamentals and General Knowledge
- Multiple difficulty levels
- Randomized questions
- 30-second timer for each question
- Question progress indicator
- Automatic score calculation
- Correct and incorrect answer tracking
- Quiz result summary
- Answer review
- High score tracking
- Restart quiz functionality
- Mobile-friendly responsive design

## How It Works

1. Select a quiz category.
2. Choose a difficulty level.
3. Start the quiz.
4. Answer the multiple-choice questions before the timer runs out.
5. View your score and performance at the end.
6. Review your answers and try again.

## Purpose

This project was developed as a practical web development project to demonstrate interactive user interfaces, quiz logic, state management and responsive web design.
